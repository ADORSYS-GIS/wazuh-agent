# Wazuh Agent Documentation

This repository contains client-side automation, deployment, enrollment, and verification scripts for the Wazuh Agent across Linux, macOS, and Windows platforms.

## Central documentation standard

This repository follows the organization-wide documentation standard defined in [`ADORSYS-GIS/wazuh`](https://github.com/ADORSYS-GIS/wazuh/blob/main/docs/DOCS-STANDARD.md).

## SDLC map

| Phase | Folder | Contents |
